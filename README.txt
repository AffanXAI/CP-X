C PROGRAMMING LAB (VSEC102) - PROGRAM COLLECTION
============================================================

1. PROJECT OVERVIEW
------------------------------------------------------------
This folder contains complete C programs for every programming task in
the C Programming Lab manual (VSEC102):

  * Experiment_01 to Experiment_11 : the 11 experiments of the manual.
    Every task of an experiment has its own .c file.
  * Appendix1_Practice_Programs    : the 'Additional List of Programs for
    Practice' (Appendix 1 of the manual), arranged week by week.
  * SAMPLE_OUTPUTS.txt             : sample input and output of the programs.
  * NOTES_Assumptions_and_Missing_Items.txt : points that were unclear in
    the manual and the assumptions that were made.

All programs use simple, standard C and compile with GCC.

3. HOW TO OPEN THE FOLDER IN VISUAL STUDIO CODE
------------------------------------------------------------
  1. Extract the ZIP file (right-click the ZIP > Extract All).
  2. Open Visual Studio Code.
  3. Click File > Open Folder... and select the extracted folder
     (Affan_C_Programming).
  4. In the Explorer panel on the left, click any .c file to open it.
  5. Open a terminal inside VS Code: Terminal > New Terminal
     (or press Ctrl + ` ). Choose the MSYS2 UCRT64 terminal profile
     if you have set it up; otherwise open the UCRT64 terminal from the
     Windows Start menu and use the 'cd' command to go to the folder.

4. HOW TO COMPILE A PROGRAM USING GCC
------------------------------------------------------------
First go to the folder of the program with the cd command. Example:

    cd Experiment_02

Then compile:

    gcc Task_01_even_odd.c -o even_odd

  - 'gcc'        : the compiler
  - first name   : the C source file
  - '-o even_odd': the name of the program to be created

If the compiler shows errors, read the line number in the message,
correct that line and compile again.

Programs that use the math library (math.h) are in Appendix 1, Week 5
(Task 21 and Task 25). In MSYS2 UCRT64 the normal command works. If you
ever get an error such as 'undefined reference to sqrt' (or 'tan'),
compile like this:

    gcc Task_21_quadratic_equation_roots.c -o quadratic -lm

5. HOW TO RUN THE COMPILED PROGRAM
------------------------------------------------------------
In the UCRT64 terminal, type:

    ./even_odd

The program starts, asks for the input and shows the result. Type each
value and press Enter. Some programs run in a loop with a menu (for
example Experiment 3 and Experiment 11); choose the Exit option to stop.

6. SPECIAL INSTRUCTIONS FOR FILE-HANDLING PROGRAMS
------------------------------------------------------------
Only Experiment_11/Task_01_employee_database_file_handling.c uses a file.

  - The program creates a text file named  employees.txt
  - The file is created in the CURRENT FOLDER OF THE TERMINAL, i.e. the
    folder from which you run the program. If you run it from inside
    the Experiment_11 folder, employees.txt appears in Experiment_11.
  - The file is created when the first employee is added. If it does not
    exist, the program simply shows 'No employee records found.'
  - Data stays in the file after the program closes, so the records are
    available the next time you run the program from the same folder.
  - Each line of the file looks like:  101|Asha Rao|Software Engineer|45000.50
  - To start with an empty database, delete employees.txt. (Delete any
    employees.txt made by an older version of this program.)

7. OTHER HELPFUL POINTS
------------------------------------------------------------
  - Fibonacci programs: the iterative one accepts N up to 90, the recursive
    ones up to 40 (recursion gets very slow for larger N).
  - Programs that read a whole line (strings with spaces) use fgets().
  - If a program reads numbers, type a number; letters will not work.
  - See SAMPLE_OUTPUTS.txt to compare your output with the expected one.
